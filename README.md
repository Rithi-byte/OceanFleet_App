# OceanFleet-App

## Overview
OceanFleet-App is a Java-based application that manages vessel performance records using Object-Oriented Programming principles.

## Features
- Create and manage vessel details.
- Store vessel records using `ArrayList`.
- Retrieve vessels using Vessel ID.
- Identify high-performance vessels based on average speed.
- Accept user input through a console interface.

## Technologies Used
- Java
- Object-Oriented Programming (OOPS)
- Java Collections Framework
- Git and GitHub

## Project Structure
```text
OceanFleet_app/

        └── java/
```

## Execution
Run `UserInterface.java` to start the application.

## Concepts Applied
Encapsulation, Abstraction, Modularity, Reusability, and Separation of Concerns.
